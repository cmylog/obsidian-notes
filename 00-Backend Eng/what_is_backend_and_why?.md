==what is backend?==
==> A backend is simply another computer on the internet whose primary job is to stay online, listen for requests from clients, process those requests, and send back responses.

==Why Do We Need a Backend?==
If browsers can already run JavaScript, why do we even need another computer?
==> The  backend exists because the frontend cannot be trusted to manage an application's important responsibilities**.

A backend provides:
- a trusted place to make decisions
- permanent data storage
- shared data for all users
- protection of sensitive information
- centralized business logic
- services that can be used by multiple clients

==**The Backend's Main Responsibility**==
==> The backend's primary responsibility is to serve clients by continuously receiving requests, processing them according to the application's rules, and sending back appropriate responses.
